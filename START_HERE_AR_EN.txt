FBRAH AI — RELEASE CANDIDATE / نسخة مرشحة للإصدار

ابدأ بقراءة RELEASE_GUIDE_AR.md أو RELEASE_GUIDE_EN.md، واقرأ RECONCILIATION_REQUIRED_AR.md قبل تشغيل المثبت.
Start with RELEASE_GUIDE_AR.md or RELEASE_GUIDE_EN.md. Read RECONCILIATION_REQUIRED_AR.md before running the installer.

التثبيت / Install:
powershell -ExecutionPolicy Bypass -File .\INSTALL_RELEASE.ps1 -ProjectRoot "C:\path\to\Fbrah-AI"

المثبت يتحقق من SHA-256، يجهّز الملفات مرحلياً، يشغّل الاختبارات قبل وبعد التثبيت، ويحفظ نسخة سابقة ويتراجع تلقائياً عند فشل الاختبار. لا يغيّر .env أو قواعد البيانات أو data أو Qdrant أو النسخ الاحتياطية.
The installer verifies SHA-256, stages files, tests before/after installation, backs up replaced files, and rolls back on test failure. It leaves .env, databases, data, Qdrant and backup folders untouched.

فحص الحزمة / Package checks:
python -m unittest -v test_release_integrity.py test_index_integrity.py
python test_priority_smoke.py

نماذج Ollama / Local models:
1) شغّل تطبيق Ollama في Windows.
2) نفّذ: ollama list
3) تأكد أن qwen2.5:7b مثبت: ollama pull qwen2.5:7b (إذا لم يكن موجوداً).
4) افتح قائمة الموديلات واضغط «تحديث نماذج Ollama» لإعادة اكتشافها فوراً.
5) عند توافر الإنترنت ومفتاح Gemini يصبح Gemini الافتراضي؛ عند انقطاع الإنترنت يختار التطبيق qwen2.5:7b إذا كان مثبتاً ومتصلًا. لا يختبر هذا الاختيار صلاحية مفتاح Gemini أو حصته.

لا يبدّل التطبيق تلقائياً بين المحلي والسحابي: التحويل السحابي داخل Gemini/GROQ فقط، والمحلي داخل Ollama فقط. لا تُعدّل .env الفعلي عبر هذه الحزمة.
