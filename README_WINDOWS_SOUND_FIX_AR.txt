إصلاح تنبيهات Windows في FBRAH
================================

سبب تقطيع النص العربي
---------------------
من المرجح أن قالب إشعار Windows يخلط النص العربي ذي الاتجاه من اليمين إلى اليسار مع اسم FBRAH أو الأرقام ذات الاتجاه من اليسار إلى اليمين دون عزل اتجاه النص. أضفنا تطبيع Unicode وعلامات عزل RTL للنص والعنوان. هذا إصلاح برمجي يستهدف المشكلة، ويجب تأكيد النتيجة على جهاز Windows لديك بعد التجربة.

تغيير الرنات
------------
كان عامل Windows يطلب نغمة Windows الافتراضية فقط. الآن يكتم صوت الإشعار الافتراضي ويولّد رنة WAV محلية قابلة للتحكم في النغمة ومستوى الصوت وعدد الدورات. النغمات الثماني: كلاسيكية، هادئة، عاجلة، متقطعة، جرس رنان، تصاعدية، رقمية، جرس مزدوج.

طريقة التثبيت
-------------
1) فك ضغط هذه الحقيبة في مجلد مستقل.
2) افتح PowerShell داخل مجلد الحقيبة (وليس Python REPL).
3) نفّذ:
   powershell -NoProfile -ExecutionPolicy Bypass -File ".\APPLY_REMINDER_SOUND_FIX.ps1" -ProjectRoot "C:\Users\hatho\Desktop\Amit\Fbrah AI\Fbrah Ai G"
4) بعد نجاح التحديث، شغّل CONFIGURE_FBRAH_WINDOWS_SOUND.bat بالنقر المزدوج.
5) اختر النغمة، مستوى الصوت، وعدد مرات التكرار.
6) أنشئ تذكيراً بعد دقيقة لاختبار إشعار Windows.

ملاحظات
-------
- لا يحتاج هذا التحديث إلى إعادة تثبيت مهمة Task Scheduler؛ المثبت يوقفها مؤقتاً ثم يعيد تشغيلها.
- يحفظ إعدادات صوت Windows في fbrah_reminder_sound.json داخل مجلد المشروع.
- مستوى الصوت يُضبط في ملف WAV نفسه، وليس بمستوى صوت Windows العام.
- خيارات صفحة FBRAH التي تحفظ في المتصفح مستقلة عن خيارات العامل الخلفي؛ هذا التحديث يوفر أداة إعداد منفصلة لإشعارات Windows.
- العامل يشغّل الصوت بصورة متزامنة بعد عرض الإشعار. لذلك لا تُستخدم قيمة «مستمر حتى الإيقاف» في العامل الخلفي، بل من 1 إلى 10 دورات لضمان استمرار فحص المواعيد.
- اختبارات الكود لا تغني عن تجربة Windows الفعلية. إذا ظل النص متقطعاً، أرسل لقطة شاشة كاملة للإشعار ونسخة Windows، وسننتقل إلى إخراج Toast XML مباشر مع ضبط اللغة واتجاه العرض.
