FBRAH AI — دليل التثبيت السريع
================================

اقرأ `READ_ME_FIRST_AR.txt` للحصول على تفاصيل التحديث والحدود والاختبارات.

1) أوقف FBRAH من PowerShell عبر Ctrl+C.
2) فك ضغط الحقيبة في مجلد مستقل.
3) افتح PowerShell داخل مجلد الحقيبة.
4) شغّل: `powershell -ExecutionPolicy Bypass -File ".\APPLY_UPDATE.ps1" -ProjectRoot "C:\مسار\مشروع FBRAH"`
5) اكتب APPLY عند طلب التأكيد.
6) أعد تشغيل FBRAH.

المثبت ينشئ نسخة احتياطية ولا يستبدل .env أو قاعدة البيانات أو data أو الملفات المرفوعة.

لتفعيل تنبيهات Windows عند إغلاق المتصفح: ثبّت `winotify` ثم شغّل `INSTALL_FBRAH_REMINDERS_STARTUP.ps1` وحدد اسم مستخدم FBRAH المستهدف.

لا توجد نكت خارجية مفعلة افتراضياً؛ لا يعرض النظام نكتاً إلا عند ضبط موجز خارجي موثوق وذي روابط مقالات فعلية.
